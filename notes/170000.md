## Techniques that mattered here
- `return x ? 1 : -1;` vs `if (x) return 1; return -1;` -> movn vs branch forms; try all.
- `int f = 0; if (a < 2) { if (a >= 0) f = ...; }` keeps two branches (no sltiu fold).
- Unused `int unused[4];` reproduces a 0x10 empty frame (func_001711F0).
- Two separate qword stores whose loads are interleaved with an unrelated float store: use a 32-byte struct copy
  (func_0017DD38).
- Chained assignment order can reproduce odd store orders (func_00173158: `a = c = b = 1`, InitZpr: `zpk = zpk2 = x`).
- `float t = g_clock.t; p->x = t + f();` forces the clock load before the call (func_00179E80).
- Early-return chains `if (a) return 0; if (b) return 0; return f();` produce the duplicated `ld ra` epilogue form;
  `int f; if (..) f = 0; else if (..) f = 0; else f = call(); return f;` produces the shared one.
- A nested if-chain on an int range: emit order follows source; the returned-last value goes in the fallthrough.

- Virtual-call temporaries must be block-scoped per call site (`{ struct O *o = ...; struct VTE *e = &o->vt[8]; ... }`);
  sharing one `o`/`e` across switch cases changes register allocation (func_0017CD00/0017D058).
- Struct-returning call into a local that is then passed by pointer (func_0017FB50): only matched as C++ with
  `MATRIX3 m; m = f(...);` (temp at sp+0x30 then copied to m at sp); C always elides the temp.
- Range test `2 <= s < 4` kept as two slti branches with `if (s < 4) { if (s >= 2 && ...) }` (func_0017A7F8).
- Message handlers `int OnMsg(S *p, int msg, M *pm)`: `if (msg == 9 && ... ) switch (pm->n8) { case X: ...; return 1; }
  return BaseOnMsg(p, msg, pm);` (func_0017B690, func_001750E0).
- Big-struct init: `struct F f; memset(&f, 0, sizeof f); f.x = ...; Send(&f);` with F = 0x60/0x70 bytes.

### Discoveries
- **Stack slot order of a qword vs. a scalar out-param**: a `union { qword q; ... }` local gets its slot at declaration
  (always first, sp+0), a plain `qword pos;` gets one only when it must live in memory (spilled across calls) - i.e. *after*
  the address-taken `float g;` out-param. Target had g at sp+0, pos at sp+0x10: plain `qword` matched (func_001789F8).
- Dist(a, b) asm register order: to get `lqc2 vf1 <- b; lqc2 vf2 <- a; vsub vf1, vf2, vf1` write
  `__asm__("vsub.xyzw %0, %2, %1" : "=j"(d) : "j"(b), "j"(a))` and call it with the operands swapped (func_001789F8).
- Inner switch whose case 0 shares the default block still needs an explicit `case 0: break;` for the dense table.
- **Switch-on-state copy register** (`daddu a1, s2` in the jump-table delay slot, case body testing `a1`): write the in-case
  test as `p->n50 == 1` (re-read the field) instead of `s == 1`; CSE replaces the load but keeps a separate pseudo/copy
  (func_0017AC90 wip, same idea as 00165B40 in notes/160000).
- func_00177E80: full permutation search with the chained `p->g34 = p->g48 = -1.0f;` *first* matched
  (`g34=g48; g64; g68; g6C; n4C; n58; nA0`).

- **`extern const` for .rodata by-value structs**: `extern const struct K D_002A5630;` lets gcc load the K (ldl/ldr) before an
  unrelated store (`p->n18C = 1`) - fixed func_0017F5B0 (target kept `this` in t0 because a2 was taken early). Probably
  applies to other "K by value" wips (func_00149A50 / func_00149B58 callers in other ranges).
- **memset in an inline C++ ctor**: `struct F { ...; F() { func_002333B4(this, 0, sizeof *this); } };` declared at the point of
  use (`F f;`) recomputes `&f` for the memset (addiu a0,sp) and puts the later `&f` in an s-reg after the call (func_00174490).
  Also there: the k==1 constant-propagation problem disappeared once the `if (m->n0 == 1 && r)` block was moved inside the
  case 1/2 body (target's case 0 jumps straight to the final `if (r)`), and `idx[j] = *(i + idx); *(i + idx) = t;` gave the
  `addu v0, v0(i<<2), sp` operand order.
- Min/max clamp (func_00177EF0): inline `Max(a,b){return a > b ? a : b;}` / `Min(a,b){return a < b ? a : b;}`, statement
  order `g64 = g; g68 = Min(g * 0.25f, D); g6C = Min(g, D2);` with `g = Max(p->g64, D3)`.
- **Register pinning solved two register-only wips**: func_001733C8 (`register int n __asm__("$3"), i "$6", qword *a "$4",
  int off "$2"` + `*(qword *)(off + (int)a) = x;` for the addu operand order) and func_00160B70 (counter in $3, pfr in $4).
  Pinning changes scheduling though (pinned hard regs get hoisted), so it failed on func_0017AC90 / func_00179898.
