# Notes for 0x1B0000-0x1C0000

## Techniques
- **sqrt.s is inline asm volatile** (SetStepSpinRatio__FP4STEPf): `1.0f / sqrtf(r)` becomes rsqrt.s under fast-math and is
  scheduled freely; the target computes sqrt.s (shows as `c1 0xC0084` in disasm - R5900 sqrt.s encodes the source in ft)
  at its source position: `static inline float SqrtF(float g) { float r; __asm__ __volatile__("sqrt.s %0, %1" : "=f"(r) : "f"(g)); return r; }`.
- `r + (c - 1)` vs `r - 1 + c` changes the reassociation/CSE (func_001BC530).
- `if (!p->x) return -1; return ...;` produced the beqz-to-tail form where `if (p->x) return ...; return -1;` did not (func_001BEE10).
- `p->i = p->c++; pe = &p->ae[p->i];` matched the scheduling (func_001BB950).
- 32-bit unsigned masks like 0xFFFFFFF0 are built lui/ori when the operand is unsigned (`cb & 0xFFFFFFF0` with unsigned cb).

### Techniques
- **Store order of asm outputs into stack unions**: write the asm outputs into plain `qword` temps and then copy
  `one.q = tone; d.q = td;` in the order the target stores them (func_001BC9F0, plane distance with W-ctor temps).
  Output operand order in the asm decides VF allocation (`"=j"(d), "=&j"(one), "=r"(dist)` with d sharing the plane reg).
- **VF value spilled across a call with lqc2/sqc2** (instead of lq/sq): use a separate plain `qword q = Make(...); u.q = q;`
  and pass `q` (not `u.q`) to the asm (func_001BF1F8).
- `pn->a[(0.0f < d) ? 1 : 0]` with constant arms is folded into a byte offset 0/2 (`addiu pn,0xC; addu`) (func_001BF110).
  `k &= 0x3FFF; return &leaf[k];` (reassign) fixed the register of the masked index.
- Tail-call cross-jumping: `if (c) i = f(p, i + 1); else i = f(p, i - 1);` gives the target's `a1 = i+1; bnez; a1 = i-1; jal`
  (a single call with ?: or if/else on the arg gives movn) (func_001BCAC0).
- Spill-slot order follows pseudo creation order: declare `int i0, r, ...` in the order of the target's spill slots;
  a qword that has GPR uses (call args, copies) gets a GPR spill slot (lq) instead of lqc2 (func_001BCAC0).
- Callee float/int param order again: func_001E6F10 is (p, qword *pv, float g, int n); vcall slot 3 of the R object
  (func_001B86B0) is (this, qword *, float, float, int); func_00204E38 is (P *p, PL *pl, float g) (pl passed AND its field).
- **Re-doing qmfc2 for each component read**: GetZ / GetX+GetY from a VF value: wrap the copy in
  `static inline qword ToGpr(qword v) { asm volatile("qmfc2.ni %0,%1" : "=r"(r) : "j"(v)); }` (volatile stops CSE), and do
  pextuw / prot3w *in place* (`asm("pextuw %0,$0,%0" : "+r"(t)); return GetX(t);`) so the output reuses the input reg
  (func_001B5E98). If the target fills the qmfc2 into a delay slot, use the plain compiler move (GetZ with "r" input on a
  VF variable) instead - asm can't go into delay slots (func_001B70A0).
- Making a reload of a union go straight to a VF reg (lqc2): assign it to the *same* qword variable that was used as a
  VF value earlier in the function (`d = u.q;`), so the pseudo keeps its VF preference (func_001B70A0).
- `vsub %0, %1, %0` with `"+j"(d)` reproduces an output that reuses the second input register (func_001B70A0); for
  matrix*vector into the vector's own register use `"+j"(v)` (func_001B86B0).
- State loop with the exit test first: `for (;;) { if (func_001EF0A8(p)) break; s = p->x30; switch (s) {...; case 2: break;}
  if (s == p->x30) break; }` (phantom `case 2` for the `beq 1; slti 2` tree, `s == p->x30` operand order) (func_001BA608).
- Target-layout of a shared `return 0` block: `if (A) return 0; if (B) { ret0: return 0; }` + `goto ret0` from the later
  failure placed the block after the right test (func_001B70A0).
- `&g_game` used 3 times: the hi-only CSE (`lui` in an s-reg, addiu per use) came out naturally here (func_001B50B0) - so it

## Round 7 (agent 7)
Matched (1): func_001B2398 (was wip, 52/52 diff).

### Techniques
- **Struct return through hidden pointer**: func_001B2398 returns a 16-byte VECTOR *by memory* (a0 = result ptr, p in a1,
  `lq v1,0(sp); sq v1,0(a0)` epilogue). A `struct { qword v; }` return is TImode and comes back in $v0 - use
  `typedef struct { float x,y,z,w; } __attribute__((aligned(16))) VEC;` and write it via `*(qword *)&r = ...`.
- **Scripted asm operand-order search**: VF register allocation of an inline asm depends on the order of its input
  operands. For the matrix*point helper the match was
  `asm("vmulax.xyz $ACC,%1,%2x; vmadday.xyz $ACC,%3,%2y; vmaddaz.xyz $ACC,%4,%2z; vmaddw.xyz %0,%5,$vf0w" : "=j"(r) : "j"(m->r[0]), "j"(v), "j"(m->r[1]), "j"(m->r[2]), "j"(m->r[3]))`
  (the vector as the 2nd operand), found by permuting all 120 input orders × {=j,=&j} in a script. Worth doing for any
  VU function whose only diffs are VF numbers.
- Normalize pattern (func_001B1160, wip): the `vsqrt` asm must write a *new* qword (`qword r; ... "=j"(r) : "j"(l)`),
  not reuse `l`, and the `vdiv`/`vmulq` asm must be `__volatile__` or gcc hoists it above the `< 1e-4f` test.
- `switch (k) { case 1: ...; case 4: ...; default: q = 0; }` gave the target's `beq 1; beq 4 (delay q=0); b` tree where
  if/else-if gave bne chains.

### Techniques
- **`while (k >= 3) { pv = ...; if (cross < 0) {...} else goto LBL; } LBL:;`** — using `goto` to a label just after the loop
  (instead of `break`) stops expand_end_loop from moving the leading exit test + body test to the loop bottom, giving the
  target's "test at top, copied test at bottom, inner test in the middle" layout (func_001BDBF0). `if (!(z < 0)) break;`
  gets reversed to c.le; `if (z < 0) {..} else goto L;` keeps `c.lt; bc1f`.
- **Loop exit test not duplicated** (target: guard before the loop, `bnel` back at the bottom, but ours had `b` to the test):
  write `i = 1; if (i < p->c) { do { ... } while (++i < p->c); }` (func_001BD8A8, func_001BD400).
- `(k > cMax - 1) ? cMax : k` with `int cMax = 32` reproduces `addiu v0,0x1F; slt v0,v0,k; movz` (constant in a register as the
  first slt operand); literal `k > 31` folds to `slti k,0x21` (func_001BDBF0).
- Separate pseudos matter for VF allocation: a first `v0 = MulPt(...)` stored 3x plus a *different* loop variable `v` gave the
  target's regs; reusing one variable did not (func_001BD040). Carrying a value with `qword v0 = v; v = MulPt(...); f(..., v0)`
  (instead of `w = MulPt; f(..v..); v = w;`) reproduced the vmove + spill pattern (func_001BD400).
- Arguments are evaluated right-to-left: put VU computations inside the call's argument list when the target computes the
  last argument (qmfc2) before the others (func_001BD400).
- `if (s) { if (s == -sgn) c++; } sgn = s;` (assignment outside the if) matched the branch into the `daddu` (func_001BC2F8);
  `switch (x) { case -1: return 4; case 1: return 3; } return 2;` for the beq chain.
- Duplicated tails `if (f(...)) { if (pf) *pf = t; return 1; }` twice (instead of a shared block) swapped the $s regs of two
  params (func_001BCF18): more references => different global-alloc priority.
- Splitting `((n / w) % 4 << 10) + (n % w << 12)` into `col = n % w; row = (n / w) % 4;` fixed the div/mod register
  allocation (func_001B2DB8).
- AREQ align: `AREQ(cb, 0x10)` with a literal 0x10 still stores the *register* holding 0x10 after an earlier `x == 0x10` test
  (cse equivalence) - func_001B2AA0's "align = ch" was really the constant.
- `int iv = f(); if (a[iv] == 0) a[iv] = 1;` gives `addu v1, v0(idx<<2), base`; `int *pf = &a[f()]` gives base first (func_001BF980).
