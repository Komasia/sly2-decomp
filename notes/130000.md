## Matching tips learned
- min.s: `p->f < x ? p->f : x` gives `min.s f0, x, f` order.
- Unused local struct (e.g. `DLI dli;`) produces an otherwise empty stack frame (PasegaFindAseg).
- C++ functions whose CRef temporaries have dtors generate EH code; write them in C with explicit
  hidden-return pointer and explicit Decref calls.
- Array indexing `a[i]` vs pointer walk changes delay slot scheduling.

### Discoveries
- **C++ guard object kept on the stack (`sw this,0(sp)` ... `lw a1,0(sp)` before the "End" virtual call)**: do NOT use a
  volatile local (volatile loads can't go in delay slots); use a plain `struct G g; g.p = p;
  __asm__ __volatile__("" : : "r"(&g) : "memory");` so &g escapes, and emit the End call at every return via a static
  inline (gcc cross-jumps the copies like a C++ dtor) - matched func_00130918. Same pattern in func_00131738 (matched
  earlier with volatile), func_00131100 / func_00130F88 (wip).
- Tagged pointer flags `x = pq->x40; ((x ^ 1) & 1) ? *(unsigned *)x : x` inside a static inline gives xori/andi/bnel with
  the value in a fresh register (func_00130918).
- Switch case layout: write cases in the order the target lays them out; a `default:` that shares code with listed cases
  (jump-table entries pointing at the default block) must be the label on that block (func_00136A90, func_00136338).
- **qword global loaded through a GPR (`lq v0` + `qmtc2` later)**: `__asm__("" : "=r"(k) : "0"(D_002A2DC0));`
  forces the pseudo into GPR class; combined with `register qword n __asm__("vf1")` for the merge variable
  (`n = k` -> qmtc2, `n = asm-result`) and a `VU *pu = &u; ... pu->q = n;` pointer for the `daddu v1,sp` +
  `sqc2 vf1,0(v1)` store (func_0013B2F0, normalise-or-default-axis). Likely solves func_0011B830 (notes/110000).
- **`1 - (a != b)` index** (sltu/subu instead of movn): fold kills it in plain C; put the compare in a static
  inline `IEnd(pa, p) { return pa->ae[0].p == p ? 0 : 1; }` and index `ae[1 - IEnd(pa, p)]` (func_00132298).
- `sizeof(arr)/sizeof(arr[0])` bound makes an unsigned compare (`sltiu`) in an int loop (func_00132298).
- Float compare ending a func with `v0=0; bc1fl v0=1`: `if (g > zero) return 0; return 1;` (func_001374F0).
- Two-way `if (A) goto shared; ... if (B) { shared: ... }` reproduces a cross-jumped branch target (func_0013AB58).
- Loop end `p->ae + p->n` written in the loop test (not a precomputed local) gives the `daddu a2,v0` copy (func_0013ADE8).
- `(T + i)->f` instead of `T[i].f` for a call through a function-pointer table swapped v0/v1 (func_0013E3C8, LO factory
  PloNew-like: table D_002BAAE8 stride 0x14, fn at +0x10). LO flag bit 60 = `int x28; signed char x2C; char x2D; long k:4;
  long :8; unsigned int f:1;` (same layout as notes/150000).
- `int i = m_ibFree;` before a virtual call fixes load order (CByteQueue::CbFill/CbDrain; CQueueOutput slot 2 = FDrain()).
- Callee declared returning a pointer (`struct CRef *func_00129970`) fixed both arg order and v0/v1 (func_00132ED8).
- Two state-loop forms: `for (;;) { s = p->x; switch...; if (p->x == s || p->y != 6) break; }` (func_00136118); do-while
  produced an entry jump.
- PingPong tail shared via a static inline helper -> gcc cross-jumps the identical tails (func_001317D8). min/max idiom:
  `*pdt = 0.0f < *pdt ? 0.0f : *pdt` -> `min.s f0, f0, f1`.
- Three-way `if (a && b) {A;B} else if (a) {A} else {B}` reproduces duplicated tails (func_0013D020).
- Separate block-scoped loop counter for the first loop fixed s-register numbering (func_0013DF80).
- Enum param types: `P3OID` mangling needs `enum OID {...}` (not typedef int).

### Discoveries
- **Scalar global vs struct store ordering**: `extern struct SO *D_003E13B4; p->c = 0; pso = D_003E13B4;` let the scheduler sink
  the `sw p->c` past the global load (gcc 2.95 alias: fixed scalar vs varying struct can't alias). Declaring the global as a
  struct (`extern struct { struct SO *p; } D_003E13B4;` + `.p`) keeps the store first (func_0013AC18). Do NOT use the
  enclosing big struct (D_003DD490.field) - gcc then CSEs the %hi with other D_003DD490 uses.
- **Register-pinning a result register**: `register T *pe __asm__("$5"); pe = base; pe += i;` (assign base then add, not
  `&base[i]`) put the element pointer in a1 like the target (func_00130B18, the "pe in a1" pattern of 00131100/00130F88).
  For values gcc coalesces anyway, add an empty `__asm__("" : "+r"(x));` after the assignment so the pinned copy survives
  (func_001333C0: node in v1 + constant 1 in v0; func_0013AC18: pe in v1). Only use when everything else matches.
- **Non-volatile mfc1 asm**: `__asm__("mfc1 %0, %1" : "=r"(q) : "f"(-g))` (not volatile) + loading the vtable fn pointer
  before the delta (`pfn = vt[n].pfn; d = vt[n].d;`) fixed the last scheduling diff of func_00135940.
- **Jump-table switch whose default shares a case body**: list *all* explicit cases (even empty `break` ones) so the range
  matches the table (sltiu N), and put `default:` on the shared block (func_00134850 first switch: default = cases 5/7/12).
- **Cross-jumped tails (case 1/7)**: `case 1: pasega = A.p; pa = &A; goto L; case 7: pasega = B.p; pa = &B; L: n = 9; ...
  f(pa);` reproduces `lw s3; b L (addiu a0)` - writing both tails in full lets the scheduler move the a0 computation.
- `if (k > 0) goto read; if (k < -2) { read: f(); }` avoids gcc's fold_range_test merging `k > 0 || k < -2` into
  `(unsigned)(k+2) > 2`; the target keeps two compares with `k < -2` saved via PRE (func_0013FB40).
- `if (p->state == 0 ? .. : ..)` -> write `(s == 0 && 0.1f < g) || (s != 0 && 0.0f < g)` and read `p->p150->x` twice (no
  local) to get the `daddu a0, v0` copy + bc1fl (func_00134850).
- Two-member CLOCK struct read `D_002DDED0.t` (struct, not float extern) fixes `lui` placement after a store (func_00136530).
- Matrix-returning callee: `M4 t = func(..., &m); m = t;` (separate temp) gives the hidden-return buffer at sp+0x40 and the
  4x lq/sq copy (func_00136530).
