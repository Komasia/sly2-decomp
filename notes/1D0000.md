## Techniques
- `extern struct G D_003DD490;` pass `&D_003DD490`.
- Varargs (func_001D89A8): EE is single-float EABI => `va_list` is `char *`; define locally
  `#define va_start(ap,last) (ap = ((char *)__builtin_next_arg(last) - (__builtin_args_info(2) >= 8 ? 0 : (8 - __builtin_args_info(2)) * 8)))`
  (stdarg.h is not on the include path).
- Switch decision tree: an extra explicit `case 1:` label sharing the default body changed gcc's compare tree to the
  target's (`beqz; bgtz; beq -1`) (func_001DA950). `case 2: return 1; case 0: case 3: return 0; case 1: default:` (func_001D55B8).
- Clamp: `if (c == 0) n = -1; else n = Clamp(i, 0, c - 1);` with an inline Clamp(n, lo, hi) (func_001DCE90); a ternary didn't match.
- Min idiom `Min(a, b) { return a < b ? a : b; }` operand order chooses movz vs movn (func_001D3FF0).
- Function returning the pointer it got from a call: if the target copies $v0 to $v1 before using it, the function
  probably returns that pointer (func_001DE5A8).
- Byte-sum loop needed an inline with an `unsigned int` counter to get `mult $zero; mflo` (func_001D7D30).
- Hash `h*33 + ToUpper(c)` matched only with ToUpper as a static inline (else gcc reassociates).
- A shared pointer local reused for two inline-call arguments gives the same register for both (func_001DF908).
