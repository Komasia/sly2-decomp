### Splice wrappers (all of 0x100000-0x110000)
Every function here is a script binding: `CRef F(void *p, int c, CRef *aref)` that unpacks args with
func_00201360 (RefSetArgsFromSplice: `CRef func_00201360(int n, void *aref, int *aotyp, ...out ptrs)`, declared
variadic - works since all outs are pointers) and calls one game function.
Template (C++, CRef class from notes/120000 Round 5):
```cpp
CRef F(void *p, int c, void *aref) {
    int ak[N] = {...};             // or `int k = X;` for N==1 (immediate store instead of ldl/ldr copy)
    union { qword q; } q0, q1;     // qword / CRef / struct outs first (in stack-slot order)
    int a; float b;                // scalar outs after (they land after `ref` on the stack)
    CRef ref = func_00201360(N, aref, ak, &a, &q0, ...);
    ref = callee(p, a, q0.q, ...);          // value result: operator= (bool: `!= 0`, int, void*, qword)
    // or for void callees:  ref.Decref(); ref.InitTag(0x24); callee(p, ...);
    return ref;
}
```
- ak (OTYP) values live in .rodata at 0x2A3A48..0x2A40A0: read with file offset 0x80 + (addr - 0x100000).
- OTYP 0x8006 / 0x8010 = CRef out-param (`CRef r;` -> `sw -1`), passed as `&r`, destroyed at the end.
  Declare `int k` BEFORE `CRef r` (else the two constant stores swap).
- A struct out of 0x40 bytes (func_0010E690: `struct { qword aq[4]; }`), passed by address.
- Callee param order = register order; floats can be anywhere (ints in a1.., floats in f12..).
- Virtual callee (func_00104E80): vptr at +0xC, slot 78: `VTE *pvte = &p->pvt[78]; pvte->pfn((char*)p + pvte->d, n, &u);`
- func_0010B340 calls with `(char *)p + 0xF50`.
- A small generator (scratch) made these mechanical: types per out param, call arg list, return kind.
