# Notes for 0x120000–0x130000 (CRef / splice runtime)

## CRef tag kinds (m_tagk at +0, payload at +4)
Inferred from the type predicates 0x120820..0x120A00 and constructors 0x129248..0x129A70:
| tagk | meaning (payload) | evidence |
|------|-------------------|----------|
| -1   | uninitialised (default ctor) | every wrapper does `ref.m_tagk = -1` |
| 0x15 | int | 0x129518 `operator=(int)`, 0x123668 float->int |
| 0x16 | float | 0x129558 `operator=(float)`, 0x123A08 |
| 0x17 | bool | all predicates return tagk 0x17 |
| 0x18, 0x19 | other scalar kinds (`operator=(x)` 0x1295D8 / 0x129618) | |
| 0x1A | VECTOR, pooled: slot heap D_00452188, node {QW vec; int cref@0x10} | 0x129248 ctor(TI), 0x129718 op=(TI), 0x1296A8 op=(const VECTOR&) |
| 0x1B | MATRIX4 (0x40), pool D_004521A0, cref@0x40 | 0x129780 |
| 0x1C | 16-byte value, pool D_004521B8, cref@0x10 | 0x129808 |
| 0x1D | 8-byte value (2 words), pool D_004521D0, cref@8 | 0x129398 ctor / 0x129878 op= |
| 0x1E | 12-byte value (3 words), pool D_004521E8, cref@0xC | 0x129408 ctor / 0x1298F0 op= |
| 0x1F, 0x20, 0x22 | refcounted object ptr, refcount at obj+0 | 0x129480/0x1294A0 ctor, 0x129970/0x1299C0/0x129A70 op= |
| 0x21 | object with vtable at +0xC, AddRef = vtbl slot 1 | 0x129A10 op= |
| 0x24 | void (TAGK_Void) | |

Pool allocator: `func_0011CCC0(SLOTHEAP*)` returns a node; ctor sets `node->cref = 0; this->p = node; node->cref++`.

## Wrapper shapes seen here (besides splicewrap.h's 4-arg form)
Many functions here are `CRef *f(CRef *ret, BASIC *pbasic, CRef *aref)` (aref in $a2, 3 args);
aref[i].m_tag at 4 + 8*i. Pattern `CRef ref; ref.m_tagk=-1; X(&ref,...); copyctor(ret,&ref); Decref(&ref)`.
A VECTOR passed/returned by value is a 128-bit TImode register: in C use
`typedef int TI __attribute__((mode(TI)));` (struct VECTOR is passed by reference in C and won't match).

## Other structs
- CSidebag (FFindBinding__8CSidebagiP4CRef): +8 first BINDING; BINDING { ?, ?, int sym @8; CRef ref @0xC; BINDING *pnext @0x14 }.
- Object with "sw" pointer: obj+8 -> SW, SW+0x90 = first LO in list, LO+0x10 = next (0x12D058, 0x12CEE0).
- 0x12D858/0x12D890/0x12D8D8: object with `O *p @0x10`, `O *q @0x1C`; O has vtbl @0x18; slot1 = attach/addref, slot2 = release.
- 0x12B6D8/0x12BB70/0x12C0E0/0x12C708: key-frame search `for(i=1;i<c-1;i++) if (g < a[i].t) break;` with stride 0x30 (t@0xC), 0x20 (t@0xC), 4, 4.
- 0x12DB50 allocates a 0x18+ record via func_0012E238 and fills +4,+8,+C,+14; 0x12DBB0/0x12DCA0/0x12DD28 are typed creators (kinds 5, 4, 7) calling func_00230018.

## Techniques that mattered
- Inline zero of a vector: `pv->x = pv->y = pv->z = 0` gives the y,z,x store order (0x12B520); needs `static __inline__`.
- Load of a global address hoisted into $s before a call -> take the address into a local first (0x125248).
- Bit 60 of a ulong flags word: `(int)(t->fl >> 60) & 1` (0x12E648).
- 0x12F938: the `movn` form comes from `(a == b) & (c == d)` with indexed `&t->a[i]`.

## Toolchain limitation
`mtc1 $x,$f; nop; cvt.s.w` — the original assembler inserted a hazard nop after mtc1 when the next insn uses
the FPR (321 cases in text.s vs 8 without). Our toolchain does not, so int->float conversions of
register values cannot match currently (0x12EF40, 0x12EEE0).

## Round 4
### BIG: VU0 code via register variables in vf regs (compiler emits lqc2/sqc2/qmfc2 itself)
`register qword a __asm__("vf1") = *(qword *)p;` (note: name "vf1", NOT "$vf1") plus asm constraint **"j"**
(VU0 float register class) makes gcc generate `lqc2`/`sqc2`/`qmfc2.ni` as normal moves, so they get scheduled
(e.g. `qmfc2.ni $a1,$vf3` in a jal delay slot) and memory loads are ordered like the original.
Asm must be NON-volatile (it has outputs) so surrounding code can move across it. Example (func_00122770, cross):
```c
register qword a __asm__("vf1") = *(qword *)aref[0].m_tag;
register qword b __asm__("vf2") = *(qword *)aref[1].m_tag;
register qword v __asm__("vf3");
__asm__ ("vopmula.xyz ACC, %1, %2\n" "vopmsub.xyz %0, %2, %1" : "=j"(v) : "j"(a), "j"(b));
func_00129248(&ref, v);   /* qword by value -> qmfc2 into $a1 */
```
- `*pd = a;` with a vf register var -> sqc2 (func_0012D958 / 0012D9D0 vadd).
- Getting a float/int result out: separate `__asm__ ("qmfc2.ni %0, %1" : "=r"(g) : "j"(a))` (int g) inside an
  inline helper (func_00122730 dot, func_001227D0 length). SFmode is not allowed in vf regs.
- `jr ra; nop` with an unfilled delay slot after a final store: `*(volatile int *)&ret->m_tag = g;` (volatile
  mem refs aren't put in delay slots).
- Splitting VU ops into separate asm statements changes where gcc schedules C stores between them (func_001227D0).
- Matched with this: 122730, 1227D0, 122770, 122B08, 122B70, 12D958, 12D9D0.

### Others
- func_0012EF40 / 0012EEE0: store rotation (write source in field order n,x,y,g; gcc rotates).
- func_0012D9D0: target loaded vptr into $a3 not $a1 -> the virtual call passes the incoming $a1/$a2 args through
  (function is (p, pv, x) and calls po->vfn(pv, x)).
- func_00120960 / 00120A20 are `tagk == X || tagk == Y` (not &&); only diff left: our reorg uses `bnel` where the
  target has `bnez` with the same delay insn (not annulled). Unsolved.
- func_00120548: default label is the "leave f uninitialised" group (out-of-range tagk skips the f=1 store);
  remaining: $a1/$t0 swap for ret vs &aref[1] + lui/sll order.

## Round 5 (CRef as a real C++ class; smart pointers; factories)
### BIG: write CRef wrappers as C++ with by-value CRef returns
```cpp
struct CRef {
    int m_tagk; union { int n; float g; void *pv; } u;
    CRef() { m_tagk = -1; }
    CRef(int tagk) { InitTag(tagk); }          // inline ctor -> InitTag call, no -1 store
    CRef(const CRef &r);                        // 0x1291A8
    void Decref();                              // 0x129EC8
    void InitTag(int tagk);                     // 0x12A0B0
    ~CRef() { Decref(); }                       // inline dtor (NOT a call with in-charge 2)
    CRef &operator=(const CRef &r);             // 0x129658
    CRef &operator=(float g); CRef &operator=(int n); CRef &operator=(bool f); // 0x129558/129518/129598
};
extern "C" CRef func_X(void *pbasic, CRef *aref);   // hidden ret ptr in $a0
CRef func_X(...) { CRef ref; ref = func_Y(...); return ref; }
```
- `ref = f(...)` where f returns CRef by value fixes the old "$a0/$a1 arg order swap" near-misses (124F00, 124F80).
- `CRef ref(0x1B)` (inline ctor calling InitTag) fixes the "&ref not CSE'd" diff (123208).
- "Return void" tails: `{ CRef r; r.Decref(); r.InitTag(0x24); return r; }` — each return path needs its OWN block
  (RefSetBinding__8CSidebagiP4CRef).
- Temps from ToFloat: `float g = func_00129DA8(&aref[0]).u.g;` (func_00129DA8 returns CRef by value) (1223C0).
- Non-inline local object ctor/dtor (func_1AE478 / func_1AE4A0(p,2)) = local class with declared ctor/dtor (125398).
### Smart pointers (refcount at obj+0)
`struct SP { T *p; void Set(T *); ~SP() { T *pt = p; if (pt && --pt->cref == 0) delete pt; } T *operator->(); };`
with NO constructor (`SP sp; sp.Set(alloc());`), T with inline `operator delete(void *pv) { func_002550F8(pv); func_0011CD98(pool, pv); }`
and members with non-inline dtors (called with a1=2). Matched 120B08, 121D20, 127C00, 128F70 (128F70 returns SP by value:
needs declared copy ctor + `return SP(sp.p)` with inline `SP(T *p) { Set(p); }`; delete via virtual/non-inline dtor -> `__dt(p,3)`).
### Factories SOLVED (the "vtable kept in $v1" pattern from notes/110000.md)

### Other techniques
- int->float clamp: inline `GLimit(float g, float gMin, float gMax)` with early returns (1233F0); `(LM*)->` member form failed.
- Loading a global's address into a local `G *pg = &D_003DD490;` placed between other loads fixes load order (124578, 1241E8).
- Loop index form matters: `apo[i]` (indexed) vs `*apo++` decides whether the pointer copy is in the loop preheader (124078).
- `int n = p->ref.u.n; parr->a[i] = n;` keeps `lw` instead of narrowed `lhu` for a short store (1252D0).
- `if (c) x = a; else x = (float)b;` instead of ?: fixes loop-increment order (120398). For `>`/`>=` write `ag[0] > ag[1]`.
- Float param first in prototype (`func_001FC408(float g, ...)`) changed integer arg scheduling (12EC50).
- 12-byte VECTOR3 by value in a 128-bit reg: pass a `union { VECTOR3 v; qword q; }` .q (12BE68, wip).
- qmfc2 straight into a float: `__asm__("qmfc2.ni %0, %1" : "=r"(g) : "j"(a))` with `float g` -> compiler mtc1 + unfilled delay slot.

### Techniques
- **Argument evaluation order**: for float args computed from the same load (`f12 = t1 - t0`, `f13 = g - t0` with t0 reused
  in f13), declare the locals in REVERSE order (`float du = g - t0; float dt = t1 - t0;`) (12C440/12CA68).
- AREQ alloc with `sw cb,0(sp)` but `sw cbAlign,4(s0)`: `AREQ *preq = &req; req.cb = x; preq->cbAlign = 0x10; f(preq)` (12EB78).
- Loader loops `ak[i].a = Read(); ak[i].b = Read();` (indexed, not `ak++`) keep the alloc result move order (12C570/12BF30).
- Smart-pointer element `operator=` declared `void` (not `SP&`) fixes v0/v1 choices after the call (121578, 127E90).
- Array element address `(int)(i * 4) + (int)sp.p + 0xC` reproduces non-strength-reduced `sll; addu; addiu 0xC` when
  the base is reloaded from memory every iteration (127E90).
- `struct.op=(alloc())` where the target computes &member after the call: `T *p = alloc(); member = p;` (126DB8).
- Factory returning one variable: `CBase *p; switch (k) { case N: p = new CN; break; ... default: p = 0; } return p;`
  with `operator new(cb) { return func_0012E1F0(cb); }`; base with 6 int fields puts the vptr at 0x18 (12E238).
  Identity matrix in the ctor: `MATRIX4 *pm = &mat; memset(pm,..); pm->m[0][0] = pm->m[1][1] = pm->m[2][2] = pm->m[3][3] = 1.0f`.
- Switch where the outer default merges with a case tail via cross-jumping: put `default: return p->ref;` FIRST in the
  outer switch (127838, the eval dispatcher). Empty `case 0: break;` gives a table starting at 0 (121F00).
- `CRef arefT[2];` arrays give the ctor/dtor countdown loops (120E10/126BA0). Store via `CRef *pres = &res; pres->u.n = 1`
  when the target addresses the local through an s-reg.
- Temps: `x = a = b = ToFloat(&pn->ref).u.g;` (temp destroyed after the stores) vs a named block temp
  `CRef r = ToFloat(..); m = r.u.g; pn = pn->pnext;` (Decref after the pointer advance) (121F00).
- Special forms cond/case/let (126A18/126BA0/126DB8): loop terminates by `pcl = 0`, body walk reuses the clause variable
  (`for (pc = pc->pnext; pc; pc = pc->pnext)`), and loops over a second list need their own variable.
- C++ copy/clone dispatch (129BC8): `switch (tagk) { case 0x1F: return CRef(func_00128CB8(..).p); ... } return CRef(*pref);`
  - NODE clone 128CB8 / W clone 12B0E8 are recursive `SP f(src, a, b)` with inline `SetNext`.
