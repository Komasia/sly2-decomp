  SHUFFLE: +0x50/54 dtPauseMin/Max, +0x58 dtPause.

## Techniques
- Function call with fewer args than registers that are still live (func_001E7380: func_001E64C8(p) only, not all args).
- CRef returned by value from func_002013D8: in C, pass &ref as hidden first arg explicitly (func_001E0310); a count
  whose address is taken needed a block temp to avoid reloads.
- `(D_002BAAE8 + i)->pfn()` vs `D_002BAAE8[i].pfn()` changed register choice (func_001ED7A8).
- Two-float copies: `{ float a = s->x; float b = s->y; d->x = a; d->y = b; }` to get load-load-store-store.
- `float uComp = 0.0f; if (x != 0.0f)` shares the zero reg (UCompleteScroller).
- Byte swap: `lo = w & 0xFF; hi = (w >> 8) & 0xFF; (lo << 8) | hi` with ushort temps (FUN_001b5c40).
- if/else whose else block appears at function end + shared store tail: `if (!a) { if (!b) return; } else { ...; stores; return; } X; stores;` (func_001E50E0).

## Session 3 (matched: 1E93F0, 1EB678, 1E5000, 1E5AE0, 1E5DF8, 1EB748, 1ECC28, 1ECE58, 1EB2F0)
- Separate loop counters per loop (`i` for loop 1, `j` for loop 2) changed s-reg priorities to match (1ECC28, 1EB748, 1EB2F0).
- `*(p->apos + i) = q` vs `p->apos[i] = q` swaps addu operand order (1E93F0); `(ulong *)((i << 3) + (int)p->a)` too (1EB678).
- Nested depth scan `switch (pe->k) { case 0: d++; break; case 1: if (--d == 0) {...goto} break; }` gave the target block order (1E5AE0).
- Inline clamp `GClamp(x, lo, hi) { if (x < lo) return lo; if (hi < x) return hi; return x; }` explains the `m - b` computed in a bc1f delay slot (1E8008).
- Branch skipping an add.s: read the branch target carefully - `b` into the instruction after add.s means that path doesn't add (1E57A0: p->f80 = D_002A8124 without + t).
- FNear (notes/1F0000) variant here is FNear(x, D_002A2DD0) calling near(X(b), X(a)) (params swapped) (1E57A0).
- Separate extern for a sub-struct global (D_002DDFA0 vs D_002DDF40+0x60) stops gcc from CSE-ing the base into $fp (1E57A0).
- Ctor-like callee declared returning its `this` pointer (func_001AE478 = mem-mark ctor, dtor func_001AE4A0(p, 2)) fixed v0/v1 (1ECE58).
- `*(ulong *)(pqw - 1) |= 0x8000` with qword* (DMA tag of last qw) - `ulong*[-2]` produced a weird -0x8000/0x7FF0 split (1ECE58).
- Shared alloc msg: inline helper taking `struct MSG *` (not its own local msg), plus a single `pe` variable reassigned per entry; `pe = &ae[2]; if (!f) Init(pe)` puts the addiu in the delay slot (1EB2F0).
- Jump tables (1EB2F0) read from disc at 0x80 + (addr - 0x100000).
