## Techniques that mattered here
- **Storing the X of a qword vector from a GPR as `sw`**: one asm `__asm__("sw %1,%0" : "=m"(m[12]) : "r"(v))`
  (gcc's own truncation gives dsll32/dsra32 first; `*(float*)&v` ICEs). func_0022CC00.
- vcall register choice ($v0/$v1 for vt vs pfn) depends on the declared return type of pfn: `int (*pfn)()`
  matched func_002240B0, `void (*pfn)()` matched func_0022B090. Try both.
- Vcall whose argument contains a call: hold `pve = &po->vt[N]; po = (char*)po + pve->d; pve->pfn(po, f(...))`
  (target keeps &vt[N] and adjusted this in s-regs) (func_002205A8).
- `g_clock` as a struct `{float t, dt}` (D_002DDED0.t) instead of `extern float D_002DDED0` changed scheduling
  of the final store (func_00221178).
- Clamp: inline `Min(a,b){return a<b?a:b;}` produced the `slt v0,const_reg,x; movz` form where if/ternary
  produced slti (func_00227D20).
- Shared loop counter `int i` across two loops (instead of separate) gave the countdown copy reg (AddVifUnpack).
- Two separate AND-masks with hoisted constants (s-regs): split into two statements via a block temp
  `{ long c = x & ~A; x = c & ~B; }` - one expression folds the constants. Bit extraction `(int)(b >> 31) & 1`
  gives the `dsll 1; dsra32` form (func_00228D20).
- Float arg position again: func_001E7380 is (void *p, qword q, float g, int, int, int, int, float *pg).
- `if (k == p->k)` + `switch (k) { case 1: ...; case 0: ... }` gave the target branch layout (func_00221178).
- `if (a || !b) n = c; else n = ...` vs `if (!a && b)` changes the branch sense (func_00227820).
- `&m2` pointer kept in an s-reg: assign `M4 *pmT = &mT;` inside the branch and use it after (func_0022FF40).

- **Struct returned through a hidden pointer from a `func_` symbol (a0 = result ptr, args start at a1)**: write it as
  C++ with a class that has a ctor, `extern "C" RGBA func_X(int k)`; C returns small structs in registers (func_002275B8,
  RGBA {r,g,b,a} with ctor; `clr = RGBA(...)` per case then `return clr`).
- **Scalar broadcast into a VF reg from a float (mfc1 + qmtc2.ni) with the dead sqc2 to a stack union**: one asm
  `__asm__("qmtc2.ni %1, %0" : "=j"(a) : "r"(t))` per scalar, then assign `u.q = a` to a `union {qword q; float f[4];}`
  local (the target keeps those dead stores). Both scalars sharing one stack slot = one union assigned twice
  (func_00220DD8 lerp `p0*(1-t) + p1*t` = `vmulax ACC, p0, b.x; vmaddx r, p1, a.x`).
- A qword returned from a call that is used only after another call: `__asm__("" : "+j"(a));` right after the first
  call makes gcc move it to a VF reg immediately (qmtc2 + sqc2 spill like the target) (func_00224698 wip).
- Linked-list unlink loop matched with an explicit `ppn`/`pnPrev` walk in the function body; the same code as an inline
  helper returning the node adds register copies (func_00229370).
- `poRet = 0;` placed *before* a call puts the zeroing in the call's delay slot and pins poRet to an s-reg
  (func_00227FE8); `goto found` from both an `if` and an inner loop reproduces the shared found-block.
- Pointer to a local struct member kept in a register (`struct CHK *pchkX = &x.chk;`) to stop gcc folding the
  accesses into sp offsets inside an inlined compare (func_0022B490).
- Vector-from-floats (pextlw/pcpyld Make asm from notes/1A0000) + GetX/GetY/GetZ matched func_0022CAD0 directly
  (rotate vector by two sin/cos pairs).

### Techniques
- `f = a < b;` (float compare into an int) gives `li 1; c.lt; bc1tl skip; li 0` and `} else f = 0;` puts the zeroing in
  the branch delay slots (func_0022A060). `if (!(a < b)) f = 0` got turned into c.le by fast-math.
- Switch decision trees: an empty `case 0: break;` changes the compare tree root (func_0022B220); inner switch case bodies must
  be in the target's layout order (func_00228538). For jump tables: list all "skip" cases explicitly and make the work block
  `default:` when the table's out-of-range branch goes there (func_0022D148).
- Outer loop over a global array with `i < sizeof(a)/sizeof(a[0])` -> sltiu; separate counters per loop (func_00224BF8).
- 64-byte struct copy with lq order r3,r0,r1,r2: `{ qword d = s.r[3], a = s.r[0], b = s.r[1], c = s.r[2]; dst = a,b,c,d }`
  (func_0022D148). Pointer locals (`M4 *pmE = &mE;`) at the top of each branch fixed the s-register numbering there.
- **Pass-through args**: a call `func_0014FCC8(p)` that is really `func_0014FCC8(p, pj, pt)` (a1/a2 untouched) fixed the
  prologue order of the param copies (func_00221A18).
- Address CSE of a global: `qword *pq = &G.q2E0; ... pq[-0x25]` reproduces `addiu v0,sym+0x2E0; lqc2 -0x250(v0)` and the
  derived `addiu s0, v0, -0x2E0` for &G (func_00221A18).
- Float max: `a > b ? a : b` operand order decides max.s operand order.
